# Arokoyu Timilehin — Portfolio

Personal portfolio site for Arokoyu Timilehin, Junior AI Front-End Engineer.

## Structure

```
.
├── index.html   # Page markup and content
├── style.css    # All styling
└── README.md
```

No build step, no dependencies — plain HTML/CSS with Google Fonts loaded via CDN.

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

Works as-is on GitHub Pages, Vercel, or Netlify — no config needed.

**GitHub Pages:** push this repo, then in Settings → Pages, set the source branch to `main` and root folder.
